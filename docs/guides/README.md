# Guides

Two guides for the people who use the app, kept in the repository so they change with the code:

- **[The admin guide](admin.md)**: for whoever runs the server. Setting up the server, Cloudflare
  and Microsoft 365, the first run, people and sign-in, alerts, backups and the restore drill,
  break-glass, updates, logs and troubleshooting, and the security in plain words.
- **[The family guide](family.md)**: for everyone in the family. Getting in, each app in everyday
  words, notifications, a page for kids, and "what if…".

They're living documents: every phase that changes what admins or the family do or see updates
them (docs/PLAN.md "How the work runs"). Screenshots and a final wording pass come once the
screens settle after Phase 44; `<!-- screenshot: … -->` comments mark where they'll go.

## Sharing them

They're plain Markdown, so they read well on GitHub or in any Markdown viewer. To hand one to the
family, ask for it to be published as a page or exported to a PDF. Both guides use the made-up
Parker family and `example.com` in their examples, and say "the app" rather than a name, because
each family names its own copy (Settings → Make it yours). Keep it that way here: put your own
details only in a copy you make for your family, never in the repository.
